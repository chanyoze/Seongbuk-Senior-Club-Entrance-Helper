  • God Method — main() 하나에 약 230줄UI·이벤트·외부 실행이 전부 한 메서드에
  • DRY 위반 — 버튼 13개의 복사 로직을 복붙 13번람다 캡처 제약으로 for문을 못 씀

  • 잔재 — 빈 Button.java · 컴파일 안 되는 Removed.java · 죽은 주석

🧪 ④ 검증의 토대

테스트 가능한 구조로

  • 🖥️ CI 러너는 GUI가 없는 '헤드리스' 환경
  • 🚫 이 앱은 GUI·마우스 후킹·클립보드라 CI에서 그대로는 테스트하기 어려움화면이 없으면 HeadlessException 발생
  • ✂️ 그래서 화면과 무관한 순수 로직만 별도 함수로 추출해 JUnit으로 테스트예: 설정 파싱 parsePrograms()

🎯 핵심: 테스트 수가 아니라 '테스트 가능하게 분리한 설계'

📄 build.gradle — JUnit 5 도입 · 테스트 실행 환경
📄 AppConfig · UsageLog · UpdateChecker — 테스트할 순수 로직 (운영 코드)
📄 AppConfigTest · UsageLogTest · UpdateCheckerTest — 실제 단위 테스트
// 화면과 무관한 '순수 함수'로 추출
static List<String> parsePrograms(String csv) {
  return Arrays.asList(csv.split("\\s*,\\s*"));
}

// 파일·화면 없이 그냥 검증
@Test
void splitsByComma() {
  assertEquals(List.of("a", "b"),
    AppConfig.parsePrograms("a, b"));
}

빌드·배포에서 막혔던 3가지

📦릴리스에 빈 zip이 올라감

증상 워크플로는 성공인데 릴리스된 zip이 460byte
원인 압축 단계가 파일명 재조립 중 인코딩 깨짐
→ 에러 없이 빈 zip 생성
해결 폴더 직접 탐지 · tar · 크기 가드 · ASCII 이름

🏷️대문자 태그 미트리거

증상 V1.2.0 push했는데 릴리스 안 돎
원인 트리거 v*가 대소문자 구분
해결 ['v*','V*']로 확장 + 태그 force 재발행

🐧Permission denied

증상 ubuntu 러너에서 ./gradlew 실행 거부
원인 git에 실행권한(+x) 비트 없음
해결 git update-index --chmod=+x gradlew
