🏛️ 출입관리 도우미

복지관 어르신 출입 기록을 돕는 프로그램입니다.
버튼 클릭으로 항목을 복사하고, 다음 클릭 위치에 자동으로 붙여넣습니다.

⬇️ 최신 버전 다운로드 (.zip)

Windows · 자바(Java) 설치 불필요 · 약 26MB

  1. 위 버튼으로 EntranceHelper.zip 을 다운로드합니다.
  2. 다운로드한 파일을 압축 풀기 합니다. (오른쪽 클릭 → 압축 풀기)
  3. 폴더 안의 EntranceHelper.exe 를 더블클릭하면 실행됩니다.
